# Picture library credits

Sitewright's starter pictures come from these free sources. Each keeps its own licence.

- **Tabler Icons** - Paweł Kuna. MIT licence (`LICENSE-tabler-icons.txt`). https://tabler.io/icons
  Outline icons, drawn here as pictures that can be tinted any colour.
- **ambientCG textures** - ambientcg.com. CC0 (public domain), no credit needed.
- **Poly Haven textures** - polyhaven.com. CC0 (public domain), no credit needed.
- **Hero Patterns** - Steve Schoger, https://heropatterns.com, licensed CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Credit stays here and in the picture dialog.
  The code that carried the patterns is MIT (`LICENSE-hero-patterns-package.txt`, Alec Lomas).
- **Simple shapes, banners and backgrounds** - drawn by Sitewright itself.
- **Thesaurus** - WordNet 3.0, Princeton University (`LICENSE-wordnet.txt`). Built into
  `thesaurus.json.gz` by `tools/build_thesaurus.py`.
