# Sitewright feature checklist

Built from the menus of WebPlus X8 (read from the program's own resource
tables) and its manual. Each task is one sitting of work. `[x]` = done in
Sitewright, `[ ]` = to do.

## Phase 1 - Core editing (File, Edit, View, Arrange)
- [x] New, Open, Save, Save As, Quit
- [x] Undo / Redo, Cut / Copy / Paste, Delete, Select All, Duplicate
- [x] Zoom in/out/actual/fit page, grid, snap to grid
- [x] Arrange: front, back, forward, back one
- [x] Revert, Recent files list
- [ ] Close All, Save as Package
- [x] Paste in Place
- [x] Paste as Unformatted Text (Paste Format still to do)
- [x] Select Similar, Lock Object
- [x] Hidden Objects (View > Show hidden objects)
- [x] Guide lines with snapping (added from the View > Guides menu)
- [ ] Rulers you drag guides from, dynamic guides, ruler marks
- [x] Zoom: page width, 50-800%
- [x] Zoom to selection
- [x] Group / ungroup; Align Objects; Size Objects
- [x] Rotate left/right, flip horizontal/vertical, rotation value
- [x] Replicate (copies in a grid)
- [ ] Attach to right / bottom of page

## Phase 2 - Pages, layouts, master pages (Insert > Pages, Site menu)
- [x] Add, copy, delete, reorder pages; page settings; master page
- [x] Site structure tree (drag to nest, parent/child pages)
- [x] Set as Home Page, Include in navigation, Insert Offsite Link
- [ ] Multiple master pages + Master Page Manager
- [x] Page from Template (4 starter layouts)
- [ ] More templates, Startup Assistant
- [ ] Page Properties: background image, colours, meta, language
- [x] HTML Fragment
- [ ] Insert HTML Page, Document Frame

## Phase 3 - Objects and extras (Insert menu)
- [x] Text frame, picture from file, rectangle, ellipse, line, button
- [ ] Artistic text, text on a path, text styles, bullets and numbering
- [ ] Picture frames, empty frame, picture crop/fit, replace picture
- [x] Photo Gallery (with lightbox)
- [ ] Panel, Slider, Rollover, Pop-up rollover
- [x] Table
- [ ] Calendar
- [x] Navigation bar (auto-built from the site structure)
- [x] Google Map, Animated Marquee
- [ ] Hotspot
- [x] Media: Video player, YouTube, Vimeo, Audio player
- [ ] Animated GIF
- [x] Forms: edit box, email box, text area, combo box, check box,
      radio button, date picker, file upload, submit (sends by email via send.php)
- [ ] CAPTCHA, form designer wizard
- [ ] E-commerce object (buy buttons, cart) via PayPal
- [ ] RSS feed / reader / podcast
- [x] Social: Facebook, X, Pinterest, WhatsApp, email share buttons
- [ ] Site search form and results

## Phase 4 - Gallery buttons and navigation styles
- [x] Button states (normal, hover, pressed), shape, gradient, shadow
- [ ] Button icons
- [x] Button gallery: 30 original styles
- [ ] Save your own buttons as assets
- [x] Navigation bar styles: horizontal, vertical, drop-down, tabs, pills, underline (10 in the gallery)
- [x] Pop-up menu for any object (hover menu, in Hyperlink box)

## Phase 5 - Themes and colour schemes (Format, Tools)
- [x] Colour schemes (12 scheme colours; changing the scheme recolours the site)
- [x] Colour Scheme Designer (8 original presets, editable)
- [x] Site-wide themes: fonts + colours + button style + navigation style (6 themes)
- [x] Fill: solid and gradient; Line and Border; Shadow; Transparency
- [ ] Picture fill
- [ ] Filter effects (blur, glow); Instant 3D
- [x] Save a selection as a style and apply it to other objects

## Phase 6 - Properties and web output
- [ ] Hyperlink dialog: page, URL, email, anchor, file, new window
- [x] Anchor (ID) field
- [ ] Actions (on click / on hover), CSS properties,
      HTML attributes, Export options, HTML Source view
- [x] Export website; preview in browser
- [x] Publish to disk folder (Export), FTP publish with progress window
- [x] Quick publish (changed files only), estimate download time
- [ ] Publish as PDF; Export as widget; Export as picture
- [x] Site Manager (pages, pictures, hyperlinks lists)
- [x] Anchors and Anchor Manager
- [ ] Font/File managers
- [x] Spell checker (uses the system's aspell)
- [ ] Find and Replace, Proof reader
- [ ] Database merge (repeating areas), HTML tokens such as %sitename%
- [ ] Options dialog and workspace save/load

## Added from the WebPlus user forum and the web (2026-10-15)
- [x] Search engine optimisation: one place per page for title, description, keywords,
      robots, social picture; site address, Google and Bing verification, Analytics
- [x] sitemap.xml, robots.txt, canonical and Open Graph / Twitter tags
- [x] RSS feed / podcast (feed.xml) with an RSS button
- [x] YouTube embed dialog (https always, autoplay, loop, related, HD, full screen)
- [x] Document frame (show another web page)
- [x] Form designer: templates, fields, themes, real contact page; PHP, mailto or other service
- [x] Clean web addresses (/about/) with no server settings needed
- [x] Heading levels, HTML id, CSS class, hidden objects and show/hide actions on whole groups
- [x] Per-page head code and CSS; page HTML source viewer
- [x] Picture optimisation on export; FTP retries and size check; site backup zip
- [x] Insert symbol (superscripts and more); help articles on HTML, CSS, meta tags, forms
- [ ] Not offered: Flash, built-in hosting (sites go to your own host)
- [x] Site search (self-hosted, works from a file too): search box and results object
- [x] Members-only pages with sign-in (PHP, hashed passwords) and a Member login object
- [x] Mailing list sign-up (saved on your host, emailed to you, private subscriber page)
- [x] Slider with Slider Studio (4 animations, autoplay, arrows, dots, swipe, keyboard)
- [x] Rollover pictures (swap, grow, brighten) and lightbox on any picture with caption
- [x] Compositions: save a selection once, reuse it on any page or site
